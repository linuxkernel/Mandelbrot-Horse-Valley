Mandelbrot Seahorse Valley 3D Terrain & Procedural PBR Shader Blender Python

Welcome to the Mandelbrot Seahorse Valley repository! This project features a unified, automated Blender Python script designed to procedurally generate high-fidelity 3D fractal terrain and companion RGBA texture maps using complex number iteration ($z = z^2 + c$). It is tailored specifically for advanced 3D digital art portfolios, procedural world-building, and GPU-accelerated graphics pipelines.

🚀 Features

  • Procedural BMesh Terrain Generation: Dynamically builds high-resolution 3D heightmaps using smoothed fractal iteration counts ($z = z^2 + c$) centered over the famous "Seahorse Valley" coordinate region of the Mandelbrot set.
  • Procedural Texture Synthesis: Generates a 1024x1024 RGBA texture map via NumPy featuring a custom sunset/crimson color gradient and high-contrast normalization.
  • Advanced PBR Gold Shader: Automatically builds and links a Principled BSDF shader featuring high metallic response (0.94), low roughness (0.16), and procedurally driven normal bump mapping.
  • Clean Automated Pipeline: Cleans up legacy data blocks, generates geometry, maps UV coordinates, packs images internally, and applies materials in a single execution click.

📋 Requirements

  • Blender 4.x / 5.x (includes Python 3.10+ and NumPy natively).
  • NVIDIA RTX or equivalent GPU recommended for real-time viewport rendering and PBR shader evaluation.

🛠️ Quick Start Guide

  1. Open Blender and navigate to the Scripting workspace.
  2. Create a new text block and paste the contents of generate_seahorse_complete.py.
  3. Click the play button (Run Script) in the text editor header.
  4. Switch to Material Preview or Rendered view in the 3D viewport to inspect your Seahorse Valley terrain!

🎛️ Texture Alignment & Mapping Controls

Pro Tip: If you need to fine-tune texture alignment in the Shading workspace:
  • Add a Texture Coordinate and Mapping node between your UVs and the Image Texture node.
  • Toggle Scale X or Scale Y to -1.0 to flip axes interactively.
